# Data

Research data are stored locally under this folder but are not committed to Git.

```text
data/
├── raw/         # source files preserved without analytical modification
├── interim/     # expensive or inspectable pipeline-stage outputs
└── processed/   # canonical analysis-ready datasets
```

The workflow documentation will record the source, expected filename, required
fields, and preparation step for every input. API keys and other credentials
must never be stored in this repository.

Stage 02 expects both park polygon sources:

```text
data/raw/parks/all parks in Metro Vancouver (2022)/merged.shp
data/raw/parks/Metro Vancouver Regional Parks/RegionalParksBoundaries_OpenData.shp
data/raw/parks/Vancouver/parks-polygon-representation/parks-polygon-representation.shp
```

The municipal source must contain `Park_Name` and `Municipali`; the regional
source must contain `parkname`. The Vancouver source supplies only the named
parks listed in `config/settings.yaml` that are absent from the 2022 inventory.
Confirmed overlaps between the sources are
reconciled as physical park entities in `config/overrides/park_entities.csv`.

The canonical shared rating input generated by the matching workflow is:

```text
data/processed/google/metro_google_ratings_validated.csv
```

Stage 06 requires `park_id`, `PlaceID`, `match_validated`, `google_rating`,
`google_review_count`, and `rating_eligible`. Its area-specific generated files
are stored under `data/interim/experience/<area>/`.

Stage 07 writes its analysis-ready DA CSV and mapped GeoPackage under
`data/interim/divergence/<area>/`. These contain primary and sensitivity
classes; they are generated artifacts rather than manually edited inputs.

Vancouver's primary sentiment input is
`data/raw/google/08c-park-metrics.csv`. It must contain `park_id`, `park_name`,
`MeanSentiment`, `TotalReviews`, and `has_valid_sentiment`. The Place ID-level
table at `data/raw/sentiment/vancouver_park_sentiment.csv` and review-level text
at `data/raw/google/08a-text-reviews-with-sentiment.csv` support Stage 11
validation and amenity analyses. These files remain local and are not committed
to Git.
