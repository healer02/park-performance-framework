# Selected outputs

This folder retains outputs used directly in the manuscript and the new
insufficient-experience diagnostics requested for review.

- `vancouver/` contains the primary sentiment-analysis outputs and both the
  rating- and sentiment-based insufficient-experience diagnostics.
- `burnaby/`, `richmond/`, `surrey/`, `new_westminster/`, and `coquitlam/`
  retain only their rating-based insufficient-experience diagnostic figure and
  supporting table.
- `metro/maps/six_city_divergence_comparison.png` is Figure 8.
- `metro/tables/six_city_transferability_summary.csv` is Table 3.

Other reproducible city outputs, row-level data, and intermediate pipeline
artifacts remain local and are intentionally excluded from version control.
