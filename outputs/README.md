# Selected outputs

This folder retains only outputs used directly in the manuscript or needed to
verify its reported results.

- `vancouver/` contains the primary sentiment-analysis figures, map, and final
  supporting tables for Sections 4.1-4.3 and the appendix.
- `metro/maps/six_city_divergence_comparison.png` is Figure 8.
- `metro/tables/six_city_transferability_summary.csv` is Table 3.

Other city-level and diagnostic outputs are generated locally by the pipeline
and are intentionally excluded from version control.
